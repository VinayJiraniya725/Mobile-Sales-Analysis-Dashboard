# 📱 Mobile Sales Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Mobile Sales Dashboard** created using **Microsoft Power BI** to analyze mobile sales performance, transactions, pricing, customer ratings, payment methods, and monthly sales trends.

## 🎯 Project priview
   (https://github.com/VinayJiraniya725/Mobile-Sales-Analysis-Dashboard/blob/main/mobile%20dashboard%201.png)


## 🎯 Project Objective

The objective of this project is to analyze mobile sales data and generate meaningful business insights that can help understand sales performance and customer purchasing patterns.

## 📊 Key KPIs

- Total Quantity: **8K**
- Average Price per Unit: **40.56K**
- Average Rating: **3.69**
- Total Transactions: **2K**
- Total Price: **61.40M**

## 📈 Dashboard Features

- 📱 Mobile Model Analysis
- 💳 Payment Method Analysis
- 📦 Units Sold by Mobile Model
- 💰 Quantity and Price Analysis
- 📅 Monthly Sales Trend
- 🗺️ Geographical Sales Analysis
- 🔎 Interactive Month Filter
- 🔎 Interactive Mobile Model Filter

## 📊 Visualizations

### Transaction by Payment Method
Analyzes transactions across:
- Credit Card
- UPI
- Debit Card
- Cash

### Units Sold by Mobile Model
Compares the number of units sold for different mobile models.

### Quantity and Price by Mobile Model
Shows the relationship between mobile quantity and price.

### Monthly Sales Trend
Tracks sales performance from January to December.

### Geographical Sales Analysis
Shows the distribution of mobile sales across different locations.

## 💡 Key Insights

- The dashboard contains approximately **8K total quantity** and **2K transactions**.
- The average mobile price is **40.56K**.
- The average customer rating is **3.69**.
- Transactions are distributed across four payment methods.
- Sales performance varies across different mobile models.
- Monthly sales show noticeable fluctuations throughout the year.
- Geographic analysis helps identify locations contributing to mobile sales.
